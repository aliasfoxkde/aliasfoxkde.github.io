Personal portfolio and documentation website for Micheal Kinney - Software Engineer & Security Researcher.

## 🌐 About This Site

This is my personal GitHub Pages website showcasing my projects, skills, and contributions to the open source community. The site features a modern, responsive design with information about my work in software development, security research, and automation.

## 🚀 Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Beautiful gradient backgrounds and smooth animations
- **Project Showcase**: Detailed information about my software projects
- **Skills Display**: Comprehensive overview of technical expertise

## 🚀 Getting Started

To use this template for your own GitHub Pages site:

1. Fork this repository
2. Rename it to `yourusername.github.io`
3. Customize the content in HTML files
4. Push your changes
5. Your site will be available at `https://yourusername.github.io`
